# Cross-attack transfer — CORRECTED states (detection and efficacy now describe the *same* attack)

**Goal of this redo.** Make the frozen-probe detection result (AUC≈1.0) and the
measured attack efficacy refer to the **same** attack. The original crossattack
`attack2` arm used a weaker dialogue scaffold that only delivered **54%** harm
(paper valence-inclusive), so "we detect it at AUC 1.0" and "the attack works"
were describing two different-strength attacks. This redo regenerates the
`attack2` internal states from the **attack2_qwen `refined_100` dialogue
scaffold** — the same scaffold behind the paper's ~80% headline — and re-runs the
whole pipeline (efficacy → transfer → 6-check leakage battery) on it.

**Bottom line.** On the corrected **80%** attack, the result is unchanged:
bidirectional cross-attack transfer at **AUC = 1.000** (all 6 probe cells, both
directions) and **all 6 leakage checks PASS**. Detection and efficacy now
describe the same attack, and the perfect AUC survives every shortcut test.

## 0. Correction to the stated premise (full disclosure)

The task framed the old states as generated by an *"OLD BROKEN denoiser (block=32,
no `fill_all_masks` — the injected blanks never filled)."* **That premise is
factually wrong, and this redo does not rest on it.** Evidence:

- The `denoise()` used by both pipelines is **byte-identical**
  (`cdg/denoise.py` ≡ `dija_attack/cdg_denoise.py`); in the `fill_all_masks=True`
  branch `block_length` is never read, so "block=32" is irrelevant.
- Every injected state — **old and new** — already carries the
  `fill_all_masks=True` signature: the `tpl_mask` count collapses toward ~1 as the
  denoise schedule completes (frac 1.00), i.e. the injected blanks **were** being
  filled:

  | family (100 injected states each) | tpl_mask @0.05 | @0.50 | **@1.00** |
  |---|---|---|---|
  | OLD attack2 (`crossattack/outputs`) | 46.9 | 39.0 | **0.81** |
  | NEW attack2 (corrected, this run)   | 50.8 | 42.2 | **0.86** |
  | DIJA (`outputs`)                    | 81.2 | 70.1 | **0.94** |

  A truly "unfilled" run would hold its mask count constant to frac 1.00. None do.

**What actually differed** between the old and corrected `attack2` states is the
**scaffold**, not the denoiser: the old crossattack arm used the shorter
`crossattack/prompts/attack2` Q&A scaffold (**54%** inclusive), whereas the
corrected arm uses the `attack2_qwen/refined_100` dialogue scaffold (**80%**
inclusive). The denoiser config is identical in both
(`llada_attack_config`: `fill_all_masks=True`, `block_length=128`, `temp=0.2`,
`steps=128`, `gen_len=128`, `low_confidence`, `mask_id=126336`, bf16).

Because this was a scaffold/efficacy difference — not a denoiser bug — the old
results are **kept in place and NOT relabeled `outputs_OLD_brokendenoiser`**
(that name would be inaccurate). They remain fully auditable at their original
paths (see §6); nothing was deleted or overwritten.

## Phase 3 — Frozen-probe cross-attack transfer (corrected states)

Setup (verbatim from `crossattack/probe/transfer.py`, unedited, imported):
`harm` scope, frac **0.05**, layers **{11,16,26}**, spaces **{hidden(4096-d),
sae(16384-d)}**, `StandardScaler → LogisticRegression(C=1.0)`. Fit on the **source
family only**, freeze, `predict_proba` on the **held-out** family — both
directions, never refit on the target. Within-family ceiling = `GroupKFold(5)`
grouped by base behavior id. Groups: DIJA {A,B,C,D}=100 each; attack2 {A(clean),
B2(injected)}=100 each.

| space / layer | within-DIJA ceiling | **DIJA→attack2** (own-clean) | **attack2→DIJA** (own-clean) |
|---|---|---|---|
| hidden / L11 | 1.000 ± 0.000 | **1.000** GENERALIZES | **1.000** GENERALIZES |
| hidden / L16 | 1.000 ± 0.000 | **1.000** GENERALIZES | **1.000** GENERALIZES |
| hidden / L26 | 1.000 ± 0.000 | **1.000** GENERALIZES | **1.000** GENERALIZES |
| sae / L11    | 1.000 ± 0.000 | **1.000** GENERALIZES | **1.000** GENERALIZES |
| sae / L16    | 1.000 ± 0.000 | **1.000** GENERALIZES | **1.000** GENERALIZES |
| sae / L26    | 0.994 ± 0.003 | **1.000** GENERALIZES | **1.000** GENERALIZES |

- `src-clean` transfer diagnostics (target injected vs *source* clean): 1.000 in
  all cells (in `transfer_results.json`).
- **TF-IDF surface floor** (attack2 injected B2 vs clean A2 behavior text, 100/100
  behavior pairs byte-identical): **AUC = 0.018 ± 0.011** — the behavior strings
  carry essentially *no* injected/clean signal, so the internal probe's 1.000 is
  not reading surface text.

The probe trained only on the DIJA (worksheet) injection separates the corrected
80% dialogue-injection `attack2` at AUC 1.000, and the reverse holds — a
mechanism that generalizes across structurally different attack families.

## Phase 4 — Six-check leakage battery (corrected states)

`crossattack/sanity/sanity_battery.py`, imported unedited; CPU-only, reusing the
captured `.pt` states; no refit on the held-out family. Each check is designed so
a **real** signal passes and a **leak** fails.

| # | Check | Expected if REAL | Observed (corrected) | Verdict |
|---|---|---|---|---|
| 1 | Label permutation (n=50) | null ≈ 0.50, true ≫ null | transfer-null **0.496** (max 0.736), within-null **0.500**; true = **1.000** > every permuted draw (p=1/51) | **PASS** |
| 2 | Prompt-only surface baseline | probe-region surface ≈ 0.50 | harm-region surface **0.500** (prompt-level 1.000, *excluded from probe*) | **PASS** |
| 3 | Length/position matching | matched; AUC stays high | harm-span mismatches **0/100** (DIJA) & **0/100** (attack2); `harm_lo≡[6]`; harm-width-only AUC **0.500**; matched-subset ceiling **0.994–1.000** | **PASS** |
| 4 | Noise / shuffled-state | ≈ 0.50 | gaussian \|Δ\|≤**0.064**, row-shuffle \|Δ\|≤**0.032**, gaussian-transfer \|Δ\|≤**0.055** from 0.50 | **PASS** |
| 5 | Grouped vs ungrouped CV | ungrouped not ≫ grouped | max(ungrouped − grouped) = **+0.000** (min −0.056; all ≤0 ⇒ grouped ceiling not inflated) | **PASS** |
| 6 | Frozen-scaler audit | fit* on source only | fits on target family = **0**, predicts on source = **0** | **PASS** |

**All 6 checks PASS.** Permuting labels or replacing states with moment-matched
Gaussian noise collapses the probe to chance (~0.50); the harm region the probe
actually reads has **no** surface length/position/mask signal (all 0.500) while
the length confound that *does* exist lives in the prompt the probe never sees
(prompt-len-only AUC 1.000, harm-region excluded); grouped and ungrouped CV agree
(no base-request memorization); and the monkeypatch audit proves the
scaler/logistic weights are fit on the source family only and never re-estimated
on the held-out attack.
